# Исправления P0/P1 в рабочей копии

## Исправлено

- Открытый `ARGS_REPR` заменён на `<redacted>`.
- Добавлено маскирование `/P`, password/pwd/pass/secret/token/cookie в диагностических командах.
- `save_json()` переведён на атомарную запись во временный файл с последующей заменой.
- Поля вкладки «Настройки программы» зарегистрированы и считываются перед сохранением.
- Подключена кнопка «Найти платформы 1С».
- Процессы 1С запускаются в отдельной process group и сохраняются в `MainWindow._active_process`.
- «Отменить» и аварийное завершение отправляют SIGTERM группе процесса с fallback на SIGKILL.
- Report-кнопки сохранения/очистки/открытия лога получили прямые обработчики.
- Видимые report-кнопки больше не используют `on_stub`.
- Галочки групп переключаются рекурсивно, состояние групп пересчитывается.
- Основные кнопки вкладки «Базы» отражают наличие выбора и целей операции.
- Backup UI использует настроенный `backup_dir`.
- Режим backup обновляет доступность полей СУБД.
- При выборе «Не использовать профиль СУБД» старые значения очищаются.
- Report fallback использует настроенный `reports_dir`.
- README, manifest и release notes синхронизированы с `VERSION=1.2.14`.
- Добавлены статические P0/P1 тесты интерфейсных привязок и маскирования.

## Требует интеграционной проверки

- GTK-клики и фактическая геометрия элементов на Ubuntu.
- Отмена реального зависшего процесса 1С и rollback.
- Сохранение Secret Service после перезагрузки системы.
- Смена file/server/web в диалогах на всех переходах.
- Вложенные группы с частичной отметкой.
- Backup/restore в пользовательском каталоге, отличном от `/mnt/DataStore`.
- Реальная работа портала 1С и PostgreSQL/MS SQL.

## Не реализовано в этом этапе

Полноценное управление кластером, systemd-расписания, пользователи, расширения, патчи, web-публикации, VSS/облака и Oracle/DB2 backup/restore.
