# Обновлятор 1С Linux 1.2.15

## Исправлено

- Убрана жёсткая привязка защищённого хранилища к коллекции `login`.
- Поддержаны GNOME Keyring, KDE KWallet, KeePassXC и другие реализации
  стандарта freedesktop.org Secret Service.
- Чтение выполняется из всех доступных коллекций, поэтому сохранённые пароли
  не теряются после смены графической оболочки или Secret Service-провайдера.
- Найденные старые записи автоматически копируются в текущую постоянную
  коллекцию.
- Добавлены резервные пути через Python keyring и `secret-tool`.
- Единый механизм применён к паролям баз 1С, ИТС, профилей СУБД и кластеров 1С.

## Безопасность

- Пароли по-прежнему не записываются в JSON-конфигурацию.
- Временная `session`-коллекция не используется для нового постоянного
  хранения.
- Запись проверяется повторным чтением из хранилища.

## Проверка

- Python-модули успешно скомпилированы.
- 25 модульных и регрессионных тестов пройдены.
- Установщик проверяет наличие нового универсального модуля Secret Service.
