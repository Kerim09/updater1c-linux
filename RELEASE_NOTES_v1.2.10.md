# Обновлятор 1С Linux — v1.2.10

Минимальное исправление постоянного хранения паролей:

- Secret Service использует только явно найденную постоянную login-коллекцию;
- сессионная или произвольная коллекция не выбирается;
- заблокированная login-коллекция возвращает явную ошибку;
- стабильный идентификатор пароля ИТС не зависит от логина;
- запись в keyring подтверждается обратным чтением;
- desktop launcher запускает полный GTK-контур с credential-механизмом.

Автоматические тесты запускаются без внешних зависимостей:

```bash
tests/run_credentials_tests.sh
```
