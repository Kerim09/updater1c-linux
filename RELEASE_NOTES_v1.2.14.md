# Обновлятор 1С Linux 1.2.14

## Назначение релиза

Релиз посвящён закрытию критических проблем P0–P1, выявленных при сравнении
Linux- и Windows-версий, и стабилизации текущего интерфейса перед добавлением
новых функций.

## Исправлено

- исключена запись паролей из диагностических файлов запуска 1С;
- добавлена атомарная запись пользовательских настроек;
- исправлено сохранение значений из вкладки настроек;
- подключена кнопка поиска платформ 1С;
- подключены отмена операции и аварийное прерывание активного процесса;
- добавлено отслеживание процессов пакетного обновления;
- исправлена рекурсивная установка отметок групп информационных баз;
- действия над базами блокируются при отсутствии корректного выбора;
- путь резервных копий берётся из текущих настроек;
- переключение режима СУБД корректно обновляет поля профиля;
- версия проекта, установщика и клиентского идентификатора синхронизирована с 1.2.14.

## Проверки

- Python syntax check: пройден;
- shell syntax check: пройден;
- unit/static tests: 22/22 пройдено;
- контрольные суммы установщика и исходного архива: проверены.

## Ограничения проверки

Интерактивная проверка GTK, Secret Service и реального запуска 1С требует
тестовой Ubuntu-системы с установленными зависимостями, платформой 1С и
тестовыми информационными базами.
