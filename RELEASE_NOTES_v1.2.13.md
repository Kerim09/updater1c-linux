# Обновлятор 1С Linux 1.2.13

## Исправлено

- Кнопка «Проверить настройки» теперь обрабатывает все отмеченные строки информационных баз последовательно.
- Строки групп не передаются в проверку и используются только для установки отметок дочерних баз.
- При проверке нескольких баз ошибка одной базы не прерывает обработку остальных.
- В отчёте проверки выводятся порядковый номер базы, результат каждой проверки и итоговая статистика.
- Если не отмечена ни одна информационная база, показывается отдельное понятное сообщение вместо ошибки о выбранной базе.

## Проверки

- Python syntax check: пройден.
- Unit tests релиза 1.2.12: 11/11 пройдено после запуска с `PYTHONPATH` проекта.
- Реальная проверка файловых, серверных и web-баз требует запуска приложения на Ubuntu с доступной платформой 1С и тестовыми базами.
