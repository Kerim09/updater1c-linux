# Обновлятор 1С Linux 1.2.17

## Основные изменения

### Исправлено скачивание обновлений конфигураций 1С

- URL `UpdateFileUrl`, полученный от `update-api.1c.ru`, используется без подмены `/public/file/tmplts/get/...` на несуществующий `/public/file/get/...`.
- Для файловых серверов 1С используется Basic Auth.
- HTTPS-редиректы обрабатываются вручную.
- Авторизация повторно передаётся только доверенным доменам `1c.ru` / `1c.eu`.
- При переходе на внешний HTTPS CDN реквизиты ИТС не передаются.
- Сохранена проверка загруженного файла и атомарная схема `.part` → готовый файл.

### Исправлено зависание интерфейса при скачивании

Загрузка конфигурационных обновлений вынесена из GTK main thread.

Используется схема:

- worker thread выполняет HTTP и файловые операции;
- worker не обращается к Gtk, Gdk, GLib или объекту окна;
- события передаются через `queue.Queue`;
- один `GLib.timeout_add()` пакетно обновляет журнал и ProgressBar;
- промежуточные события прогресса объединяются;
- повторный параллельный запуск скачивания блокируется.

### Исправления исходной базы

Исходный код синхронизирован с фактическим payload релиза 1.2.16, в том числе с `core/onec_download_client.py`.

Source archive релиза 1.2.17 формируется непосредственно из Git commit, чтобы исходники и бинарный payload одного релиза больше не расходились.
