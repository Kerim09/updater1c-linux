# Updater1C Linux — единый план P0/P1

План объединяет критические выводы сравнительного аудита Windows/Linux и аудит поведения GTK-интерфейса. Новые функции Windows не добавляются, пока не закрыты текущие дефекты.

## P0 — закрыто в этой рабочей копии

- [x] Маскирование аргументов 1С и удаление открытого `ARGS_REPR` из временного диагностического файла.
- [x] Атомарное сохранение JSON-конфигурации с безопасным режимом нового файла.
- [x] Сбор значений полей вкладки «Настройки программы» перед сохранением.
- [x] Подключение кнопки «Найти платформы 1С».
- [x] Отслеживание процессов 1С и запуск в отдельной process group.
- [x] Реакция кнопок отмены на SIGTERM/SIGKILL группы процесса.
- [x] Удаление видимых report-stub привязок для скачивания обновлений и отмены.
- [x] Прямые обработчики сохранения, очистки и открытия текущего лога.
- [ ] Интерактивно подтвердить Secret Service после перезагрузки Ubuntu.

## P1 — закрыто частично в этой рабочей копии

- [x] Рекурсивное переключение галочек групп и пересчёт состояния родителей.
- [x] Доступность основных кнопок по текущему выбору/наличию целей.
- [x] Использование настроенного `backup_dir` в backup UI и backup combo.
- [x] Обновление полей СУБД при смене backup-режима.
- [x] Очистка полей профиля при выборе «Не использовать профиль СУБД».
- [x] Использование настроенного `reports_dir` в report patch fallback.
- [x] Синхронизация версии README/manifest/release notes с `VERSION=1.2.14`.
- [ ] Перевести все patch-модули на явные ссылки/ID вместо поиска по тексту.
- [ ] Полностью свести backup plugin/hotfix/combo bridge после GTK smoke-теста.
- [ ] Добавить полноценные JSON-результаты по каждой базе.

## Не входит в P0/P1

Полноценное управление кластером 1С, systemd-расписания, пользователи, расширения, патчи, web-публикации, VSS-аналоги, облака и backup/restore Oracle/DB2.

## Критерии перед следующим этапом

1. Нет открытых секретов в логах и `/tmp`.
2. Настройки переживают перезапуск и реально используются операциями.
3. Cancel/emergency stop завершают процесс и корректно отражаются в отчёте.
4. Группы, web/file/server и backup-профили не дают противоречивого UI.
5. Пройдены GTK smoke-тесты на Ubuntu с установленной 1С.
