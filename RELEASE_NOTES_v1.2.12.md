# Обновлятор 1С Linux 1.2.12

## Что изменено

- GTK runtime стал единственным runtime установочного payload.
- Добавлен Qt-free клиент каталога `releases.1c.ru` с ticket-авторизацией.
- Разделены три сценария загрузки: платформа, обновление `.cfu` и полный дистрибутив `.cf`.
- Добавлена команда «Полный дистрибутив» и отдельное хранение в каталоге `full_<версия>`.
- Цепочка обновлений конфигурации продолжает использовать `update-api.1c.ru` и `upgradeSequence`.
- Убрано сохранение паролей ИТС, DBMS и кластеров в JSON; основной путь — Secret Service.
- Установщик сохраняет пользовательские настройки, базы, каталоги загрузок и резервные копии.
- Канонический desktop-файл: `io.github.kerim.updater1clinux.desktop`.
- Установщик устанавливает недостающие GTK, requests и Secret Service зависимости с видимым прогрессом.

## Проверки

- Python/Bash syntax check: пройден.
- Unit tests: 11/11 пройдено.
- Payload установщика: один launcher, один desktop-файл, без Qt entry points и резервных исходников.
- Реальные скачивания через учётную запись ИТС и тестирование на Ubuntu/Astra Linux требуют отдельной тестовой машины и учётной записи.
