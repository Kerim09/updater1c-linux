# Обновлятор 1С Linux 1.2.16

## Исправлено

- Исправлено скачивание обновлений конфигураций с защищённых файловых
  серверов `dl*.1c.ru`.
- Вместо отдельного запроса с Basic Auth используется постоянная HTTP-сессия:
  вход через форму `login.1c.ru`, возврат на файловый сервер и повторное
  использование выданных cookies.
- При истечении сессии выполняется одна повторная авторизация после ответа
  `401` или перенаправления на страницу входа.
- Убран перебор прямых HTTP/HTTPS-ссылок и вариантов регистра имени файла.
  Приложение использует URL из update-api и совместимый endpoint `file/get`.
- Сообщение об отказе авторизации теперь указывает на ИТС-доступ, а не выводит
  длинный список одинаковых ошибок по вымышленным адресам.

## Безопасность

- Логин и пароль ИТС не записываются в журнал и не сохраняются в проекте.
- Cookies авторизации существуют только в памяти процесса приложения.
- Загрузка по незашифрованному HTTP больше не используется для обновлений
  конфигураций.

## Проверка

- Добавлены тесты входа через CAS/form-login, повторного использования cookies
  и однократной повторной авторизации после `401 Unauthorized`.
- Python- и Bash-синтаксис проверены.
- Все 28 модульных и регрессионных тестов пройдены.
