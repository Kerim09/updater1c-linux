# Обновлятор 1C Linux 1.2

## Главное

- Добавлено рабочее скачивание платформы 1С через releases.1c.ru/version_file с form-login.
- Реализован выбор реальных файлов релиза со страницы releases.1c.ru/version_files.
- Исправлено ранжирование пакетов:
  - Windows thin client выбирает setuptc64_*.rar;
  - DEB thin client выбирает thin.client_*.deb64.zip;
  - generic Linux thin client выбирает отдельный Linux-пакет, а не DEB/RPM;
  - серверные/all_clients пакеты не подмешиваются к тонкому клиенту.
- Добавлен прогресс скачивания через горизонтальный progressbar.
- Убран шумный лог процентов скачивания.
- Добавлена кнопка открытия папки с платформами.
- Добавлена кнопка скачивания платформы во вкладку “Отчет”.
- Добавлена корректная распаковка архивов:
  - zip/tar/rar и распространенные архивы распаковываются;
  - bin/run/deb/rpm/msi/exe/dmg не распаковываются;
  - bin/run делаются исполняемыми;
  - папка распаковки получает имя архива.
- Для RAR используется file-roller, то есть поведение близко к двойному клику в файловом менеджере.
- Архив удаляется только после успешной распаковки.
- Добавлена обработка отмены скачивания и удаление недокачанного .part-файла.
- Отключен старый ticket-fallback, который не активировал cookie releases.1c.ru.
- Улучшен отчет выполнения и кнопки открытия папок.

## Проверено

- Windows thin client 8.5.1.1343: setuptc64_8_5_1_1343.rar.
- DEB thin client 8.5.1.1343: thin.client_8_5_1_1343.deb64.zip.
- Linux thin client 8.3/8.5: отдельные Linux zip/bin-пакеты.
- Распаковка zip в папку с именем архива.
- RAR остается как архив, если системный backend не смог распаковать.
